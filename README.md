# UltraCam 2.0 — камера с зумом 0.5× … 150×, Pro-режимом и ИИ

Работает полностью офлайн (разрешение INTERNET не запрашивается).

## Что нового в 2.0
**Зум**
- до **150×**: аппаратный → цифровой хвост; пресеты 0.5 · 1 · 2 · 5 · 10 · 50 · 100 · 150
- **плавные переходы**: нажатие на пресет плавно «едет» по логарифмической шкале, а не прыгает
- смена объектива (0.5× ↔ 1×) прячется под «замороженным кадром» с плавным растворением — без чёрной вспышки
- **любое значение**: щипок пальцами, ползунок (тап по цифре зума) и ввод числа (долгое нажатие на цифру: 2.5, 3.5, 12…)
- кнопки громкости можно переключить на зум (⚙)

**0.5×**
- ищется всеми способами: зум < 1× у основной камеры (логическая мульти-камера) или отдельная сверхширокая камера
- ⚙ → «О камерах…» показывает, что реально отдаёт телефон
- Без сверхширокого объектива шире 1× снять физически нельзя (поля зрения просто нет) — тогда кнопка 0.5 тусклая и объясняет причину

**Стабилизация** (кнопка «〰 Стаб»: Выкл / Обычная / Супер)
- оптическая (OIS) + электронная (EIS) + «Супер» = preview-стабилизация (Android 13+, если камера умеет)
- HUD показывает, что реально включилось: `СТАБ: OIS+EIS`
- если «Супер» не запустилась — автоматически откатывается на «Обычную»
- **Горизонт-лок** 🧭: превью и фото выравниваются по горизонту (до ±20°), по акселерометру
- **Гиро-спуск**: перед снимком ждёт, пока рука замрёт
- видео: превью 16:9 целиком — видишь ровно то, что пишется

**Pro-режим (как Blackmagic Camera)** — кнопка 🎛 PRO
- ручные ISO, выдержка, фокус (MF), баланс белого (пресеты), EV; блокировка AE / AWB; долгое нажатие на экран = AE/AF lock
- Скопы 📊: **зебра**, **пиковка фокуса**, **гистограмма**, **ложные цвета**
- сетки: 3×3, золотое сечение, 4×4, крест; рамки 1:1 · 4:5 · 9:16 · 2.39 (фото обрезаются по рамке)
- видео: 4K / 1080p / 720p × 24 / 30 / 60 fps; HUD: ISO · выдержка · фокус · стабилизация
- Looks для фото: Натурал, Яркий, Кино, Ч/Б, Тёплый, Холодный

**Качество / ИИ**
- **Стек ×8**: серия кадров выравнивается (субпиксельно) и склеивается — настоящее суперразрешение; включается на цифровом зуме от ~3×
- **Умный ×4**: из 4 кадров берётся самый резкий
- ИИ-плагин (.tflite) + «Сила ИИ» (100 / 70 / 40%) — смесь с обычным масштабированием, меньше «выдуманных» деталей
- кроп для зума декодируется прямо из JPEG — не грузит память

## Как получить APK (через GitHub)
1. Залей папку проекта в репозиторий на GitHub (ветка main).
2. Вкладка Actions → «Build APK» → Run workflow (запускается и сам при каждом push).
3. Через ~5–8 минут APK появится: Releases → скачать .apk, либо Actions → последний запуск → Artifacts.
4. Установи APK (разреши установку из неизвестных источников).

## ИИ-модель
Подходит любая .tflite с фиксированным входом [1,H,W,3] и выходом [1,H·k,W·k,3]
(ESRGAN, Real-ESRGAN и т.п., float32 или uint8, k ≥ 2).
- В приложении: 🧠 → «Выбрать модель». Если картинка пересвечена/тёмная — переключи «Диапазон входа» 0–1 ↔ 0–255.
- Или положи файл в `app/src/main/assets/models/sr.tflite` до сборки — он вшьётся в APK.
ИИ применяется к фото, когда зум вышел за аппаратный предел и кроп ≤ 0.8 Мп.

## Ограничения (честно)
- 0.5× нужен реальный сверхширокий объектив, который телефон отдаёт приложениям (см. ⚙ → О камерах).
- В видео зум только аппаратный (цифровой хвост до 150× — только в фото).
- Горизонт-лок и стек работают в фото; в видео стабилизация — средствами камеры телефона (OIS/EIS), без своей обработки кадров.
- Цифровой зум не добавляет реальных деталей: стек и ИИ улучшают вид, но на 100×+ это не чудо.
- Ручные ISO/выдержка/фокус работают, только если камера телефона их поддерживает.
- Минимум Android 10.
